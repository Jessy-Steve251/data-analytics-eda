# Data Analytics & Exploratory Data Analysis

Exploratory data analysis, clustering, statistical modelling, and interactive visualization — turning raw data into insight a decision-maker can act on.

## Projects

### `housing_price_eda_clustering.ipynb`
An end-to-end EDA of housing-price data: missing-data profiling, feature exploration, KMeans clustering with silhouette / Calinski-Harabasz validation, geospatial visualization with Folium heatmaps, and an interactive Dash dashboard. Academic workshop built on a provided scaffold; the analysis, clustering and visualizations are my own.

### `statistical_modelling_distributions.ipynb`
A phased statistical study fitting and comparing continuous distributions (gamma, beta and others) with SciPy, including distribution fitting and visual diagnostics. Demonstrates applied probability and statistics beyond descriptive summaries.

## Stack
Python · pandas · scikit-learn (KMeans) · SciPy · seaborn · Matplotlib · Folium · Dash · missingno

## Notes
Developed in Google Colab. Datasets are not committed; each notebook documents its source.
